# 文献摘要1：社区获得性肺炎门诊分层管理（综述）
结论要点：
1. 发热+咳嗽+咳脓痰是门诊肺部感染高频组合症状。
2. 血常规联合CRP/PCT可提升感染分层效率。
3. 胸片或低剂量CT有助于区分上呼吸道感染与肺实质受累。
4. 对老年或慢病患者，早期评估氧合状态可降低延误风险。

# 文献摘要2：急性腹痛初诊流程的真实世界研究
结论要点：
1. 急性腹痛患者中，约20%-30%需影像学进一步明确病因。
2. 持续性腹痛伴呕吐或发热，急腹症概率显著上升。
3. 体格检查+炎症指标+超声可作为基层首轮诊断组合。

# 文献摘要3：化妆品相关接触性皮炎流行病学分析
结论要点：
1. 面部红斑、瘙痒、灼热是最常见就诊主诉。
2. 香精、防腐剂、表面活性剂是高频致敏成分。
3. 停用可疑产品并尽早皮肤屏障修复，可缩短病程。

# 文献摘要4：呼吸困难风险分层研究
结论要点：
1. 呼吸频率升高与血氧下降是重症风险的重要预测信号。
2. 合并胸痛、意识改变时需立即升级评估路径。
3. 血气分析与胸部影像联合可提高病因识别效率。

# 文献摘要5：泌尿道感染诊疗证据总结
结论要点：
1. 尿频尿急尿痛的典型三联征对下尿路感染有较高提示价值。
2. 合并高热和腰痛时需警惕上尿路感染。
3. 尿培养结果可用于后续精准用药调整。

# 文献摘要6：慢性咳嗽鉴别诊断研究
结论要点：
1. 慢性咳嗽病因常见为上气道咳嗽综合征、哮喘、胃食管反流。
2. 咳痰性状（白痰/黄痰）与是否合并发热对感染判断有辅助价值。
3. 分步评估可减少不必要影像检查。

# 文献摘要7：急性胸痛门急诊分层研究
结论要点：
1. 心电图+肌钙蛋白是首轮分层核心。
2. 胸痛持续时间、放射痛和自主神经症状与高风险事件相关。
3. 低风险患者可在短期复评路径下减少过度住院。

# 文献摘要8：面部接触性皮炎随访研究
结论要点：
1. 去除诱因后72小时内症状改善率明显提高。
2. 皮肤屏障修复联合抗过敏治疗可缩短病程。
3. 复发与再次接触致敏成分高度相关。

# 文献摘要9：糖代谢异常早筛策略
结论要点：
1. 多饮多尿伴体重下降时，空腹血糖与HbA1c联合筛查价值更高。
2. 尿酮体阳性与急性代谢失衡风险上升相关。
3. 早期生活方式干预可显著降低短期再就诊率。

# 文献摘要10：急性咽痛与上呼吸道感染分层
结论要点：
1. 咽痛合并鼻塞流涕时病毒性上呼吸道感染更常见。
2. 高热、扁桃体渗出和颈部淋巴结肿大提示细菌感染概率上升。
3. 对症治疗和短期复评可减少不必要抗菌药使用。

# 文献摘要11：卒中早期识别与转诊研究
结论要点：
1. 突发言语障碍、偏瘫、口角歪斜是脑血管事件的重要警示信号。
2. 发病时间窗记录直接影响影像选择和再灌注治疗机会。
3. 基层场景中快速识别并转诊可降低延误。

# 文献摘要12：急性腰痛与泌尿结石鉴别
结论要点：
1. 腰痛伴血尿需考虑泌尿系结石或感染。
2. 发热、寒战和肾区叩痛提示上尿路感染风险。
3. 尿检联合泌尿系超声可作为初筛组合。

# 文献摘要13：失眠焦虑基层筛查
结论要点：
1. 失眠持续超过2周并影响日间功能时建议量表评估。
2. 焦虑、抑郁和躯体疾病可相互影响，需要同时排查。
3. 自伤风险评估是精神心理主诉的安全底线。

# 文献摘要14：异常子宫出血初诊路径
结论要点：
1. 育龄期异常出血首先应排除妊娠相关问题。
2. 血常规和盆腔超声有助于判断失血程度和器质性病变。
3. 出血量大或伴晕厥时需急诊处理。
