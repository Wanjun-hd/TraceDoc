# C201 吐血急症相似病例
主诉：突然吐血约200ml。现病史：呕吐鲜红色血液，伴头晕。初步判断：上消化道出血可能。处置：立即急诊评估生命体征、血常规、凝血功能和急诊胃镜。

# C202 跌倒后嗜睡相似病例
主诉：老人跌倒后头疼。现病史：头部出血，之后嗜睡并恶心。初步判断：需优先排除颅内出血。处置：立即急诊神经系统查体和头颅 CT。

# C203 伤口流脓相似病例
主诉：外伤后伤口流脓。现病史：伤口周围红肿，出现黑色分泌物。初步判断：伤口感染或蜂窝织炎可能。处置：尽快线下清创和抗感染评估。

# C204 烫伤水泡相似病例
主诉：热水烫伤后灼痛。现病史：局部皮肤起水泡。初步判断：浅二度烫伤可能。处置：流动凉水冲洗、清洁覆盖并评估创面。

# C205 冻伤麻木相似病例
主诉：低温暴露后皮肤麻木。现病史：复温后发痒。初步判断：轻度冻伤可能。处置：缓慢复温并观察皮肤颜色、感觉和循环。

# C206 鼻出血相似病例
主诉：鼻流血。现病史：鼻前部持续渗血。初步判断：鼻前部黏膜出血可能。处置：身体前倾并持续捏紧鼻翼，未缓解时耳鼻喉科就医。

# C207 耳痛流脓相似病例
主诉：耳痛流脓。现病史：耳痒、听力下降和耳道分泌物。初步判断：外耳道炎或中耳炎可能。处置：耳镜检查并保持耳道干燥。

# C208 空腹心悸乏力相似病例
主诉：空腹后心悸乏力。现病史：偶有腹泻，进食后缓解。初步判断：需优先排查低血糖。处置：测量指尖血糖，意识清醒时及时补糖。

# C209 肘部关节疼痛相似病例
主诉：肘部疼痛。现病史：活动后加重，关节活动受限。初步判断：骨关节或软组织劳损可能。处置：查体并根据外伤史和持续时间考虑 X 线或超声。
