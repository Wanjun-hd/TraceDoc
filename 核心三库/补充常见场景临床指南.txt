# G201 消化道出血急诊路径
吐血、呕血、咖啡色液体或黑便提示消化道出血。呕吐鲜红色血液属于急症，应立即急诊，评估生命体征、血常规、凝血功能、交叉配血，必要时急诊胃镜。

# G202 头部外伤危险信号路径
跌倒、撞头或头部出血后出现持续头痛、嗜睡、恶心呕吐、意识改变、肢体无力时，应立即急诊排除颅内出血。通常需神经系统查体和头颅 CT。

# G203 伤口感染处理路径
外伤后伤口流脓、破溃、红肿热痛或出现黑色分泌物，应警惕伤口感染、蜂窝织炎、脓肿或坏死性软组织感染。红肿扩散、发热或黑色坏死样分泌物需尽快就医。

# G204 烧伤烫伤处理路径
热水或热源导致皮肤水泡和灼痛时，应评估烧伤面积、深度和部位。早期使用流动凉水冲洗约20分钟，覆盖清洁敷料，不要自行挑破水泡。

# G205 冻伤处理路径
低温暴露后皮肤麻木、发痒、苍白或水泡提示冻伤。应脱离低温环境并温水缓慢复温，避免揉搓和直接火烤。持续麻木、水泡或全身症状需就医。

# G206 鼻出血处理路径
鼻前部渗血常见于鼻腔黏膜出血。身体前倾，捏紧鼻翼持续按压10至15分钟。持续出血超过15至20分钟、出血量大或伴头晕乏力时需就医。

# G207 耳道流脓处理路径
耳痛、耳痒、听力下降和耳道流脓提示外耳道炎、中耳炎或鼓膜穿孔可能。应保持耳道干燥，尽快耳镜检查，避免自行掏耳或滴入不明药物。

# G208 低血糖风险筛查路径
空腹后出现心悸、手抖、冷汗和乏力时，应尽快测量指尖血糖。意识清醒时可补充含糖食物；意识模糊、晕厥或抽搐时应立即急救。

# G209 骨关节疼痛评估路径
肘部或其他关节疼痛、活动后加重时，应评估压痛、肿胀和活动范围。持续疼痛、有外伤史或功能受限时考虑 X 线或超声检查。
