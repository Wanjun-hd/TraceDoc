# 病例1（呼吸道）
主诉：咳嗽、咳黄痰、发热3天，活动后气短1天。  
现病史：受凉后起病，体温最高38.7℃，口服感冒药无明显缓解。  
检查：WBC升高，CRP升高，胸部影像示下肺斑片影。  
诊断倾向：社区获得性肺炎。  
处置：抗感染+雾化+补液，对症后体温下降，咳痰减少。

# 病例2（皮肤过敏）
主诉：面部红斑、瘙痒2天。  
现病史：使用新粉底液后次日出现双颊红肿、瘙痒，停用后仍反复。  
检查：皮损局限于接触部位，斑贴试验对香精阳性。  
诊断倾向：化妆品相关变应性接触性皮炎。  
处置：停用可疑产品，抗过敏+屏障修复，7天明显缓解。

# 病例3（腹痛）
主诉：上腹痛伴恶心呕吐1天。  
现病史：油腻饮食后发作，持续性疼痛，无黑便。  
检查：腹部压痛，炎症指标轻度升高，腹部超声未见急性外科征。  
诊断倾向：急性胃肠功能紊乱/胃炎。  
处置：补液、抑酸、止吐，对症后改善。

# 病例4（泌尿系统）
主诉：尿频、尿急、尿痛2天。  
现病史：排尿末端疼痛，无明显腰痛。  
检查：尿常规白细胞阳性，亚硝酸盐阳性。  
诊断倾向：急性膀胱炎。  
处置：经验性抗感染，复查尿常规好转。

# 病例5（神经系统风险）
主诉：突发头痛伴短暂意识不清。  
现病史：无外伤史，发作时伴恶心。  
检查：急诊头颅CT未见出血，电解质轻度紊乱。  
诊断倾向：需排查血管性头痛与代谢相关意识障碍。  
处置：先稳态处理并完善MRI，后续专科随访。

# 病例6（胸痛）
主诉：活动后胸痛伴心悸2天。  
现病史：劳累后胸前区压榨样疼痛，每次持续约10分钟。  
检查：心电图示ST-T改变，肌钙蛋白临界升高。  
诊断倾向：急性冠脉综合征待排。  
处置：监护下进一步评估并给予抗缺血治疗。

# 病例7（高血糖）
主诉：口渴、多尿、乏力1月。  
现病史：体重下降约3kg，夜尿增多。  
检查：空腹血糖升高，HbA1c升高，尿酮体阴性。  
诊断倾向：2型糖尿病初诊。  
处置：饮食运动干预+口服降糖药，门诊随访。

# 病例8（急性胃肠炎）
主诉：腹泻伴腹痛1天。  
现病史：不洁饮食后出现腹泻6次，轻度恶心。  
检查：电解质轻度紊乱，炎症指标轻度升高。  
诊断倾向：急性胃肠炎。  
处置：口服补液盐+对症治疗，2天后明显缓解。

# 病例9（上呼吸道感染）
主诉：咽痛、鼻塞、流涕2天。  
现病史：受凉后出现咽痛和清水样鼻涕，无呼吸困难。  
检查：体温37.8℃，咽部轻度充血，肺部听诊未见明显异常。  
诊断倾向：普通上呼吸道感染。  
处置：对症治疗、补液休息，3天后症状减轻。

# 病例10（卒中风险）
主诉：突发言语不清伴右侧肢体乏力1小时。  
现病史：既往高血压，发作时无明显外伤。  
检查：血压升高，神经查体提示右侧肌力下降。  
诊断倾向：急性脑血管事件待排。  
处置：记录发病时间，急诊绿色通道完善头颅影像。

# 病例11（腰痛血尿）
主诉：右侧腰痛伴血尿半天。  
现病史：阵发性绞痛，向腹股沟放射，无明显高热。  
检查：尿常规红细胞阳性，泌尿系超声提示输尿管结石可能。  
诊断倾向：泌尿系结石。  
处置：镇痛、补液，泌尿外科随访评估排石或进一步处理。

# 病例12（失眠焦虑）
主诉：入睡困难伴焦虑2周。  
现病史：工作压力增加后出现入睡时间延长，白天注意力下降，无自伤意念。  
检查：焦虑量表轻中度，甲状腺功能未见明显异常。  
诊断倾向：焦虑相关失眠。  
处置：睡眠卫生干预、心理支持，必要时专科随访。

# 病例13（异常出血）
主诉：下腹坠痛伴阴道异常出血1天。  
现病史：月经推迟后出现少量出血，伴阵发性下腹痛。  
检查：血常规轻度贫血，妊娠试验待复核，盆腔超声建议进一步评估。  
诊断倾向：妇科急症待排。  
处置：完善妊娠相关检查和超声，必要时妇科急诊处理。
